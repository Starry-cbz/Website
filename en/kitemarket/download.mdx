## Server owners: choose exactly one runtime {#server-owners-choose-exactly-one-runtime}

| Distribution | Target Minecraft range | Plugin bytecode | 1.0.0 filename |
| --- | --- | --- | --- |
| Legacy | 1.16.5–1.20.4 | Java 11 | `KiteMarket-legacy-1.0.0.jar` |
| Modern | 1.20.5–1.21.11 | Java 21 | `KiteMarket-modern-1.0.0.jar` |
| Current | 26.2 | Java 25 | `KiteMarket-current-1.0.0.jar` |

Install only the matching main-plugin JAR in `plugins/`. The server JVM must meet the server software's own requirements; Legacy bytecode does not mean all older servers can use Java 11. Prepare ItemsAdder and economy plugins separately.

## Developers: SDKs, sources and examples {#developers-sdks-sources-and-examples}

| Purpose | Filename |
| --- | --- |
| Read-only market queries and trade notifications | `KiteMarket-API-1.0.0.jar` |
| Market API sources / Javadoc | `KiteMarket-API-1.0.0-sources.jar` / `KiteMarket-API-1.0.0-javadoc.jar` |
| Page and theme rendering interfaces | `KiteMarket-UI-API-1.0.0.jar` |
| UI API sources / Javadoc | `KiteMarket-UI-API-1.0.0-sources.jar` / `KiteMarket-UI-API-1.0.0-javadoc.jar` |
| Runnable query and IA extension examples | `KiteMarket-Examples-1.0.0.zip` |

Both SDKs target Java 11 with MIT licenses. Use `compileOnly` or `provided`: **do not bundle or relocate the SDKs**. Do not install API, sources or Javadoc JARs in the server's `plugins/`. The host plugin supplies the services; SDKs do not replace its license.

The GitHub Packages registry is `https://maven.pkg.github.com/kitemc/KiteMarket`, with coordinates `com.kitemc:kitemarket-api:1.0.0` and `com.kitemc:kitemarket-ui-api:1.0.0`. Packages dependencies require authentication; Release-file downloads do not. Check that the requested version is published in Packages before using it.

V1.1 candidate sources and new DTOs use `1.1.0` coordinates; see [SDK dependencies](/en/kitemarket/api/dependencies). Changing a coordinate cannot retrieve an unpublished version, and v1.0 SDKs do not supply new interfaces.

## Configuration and integrity {#configuration-and-integrity}

The configuration bundles are `KiteMarket-config-zh_CN-1.0.0.zip` and `KiteMarket-config-en_US-1.0.0.zip`; checksums are in `SHA256SUMS.txt`. All are listed with the corresponding GitHub Release.

Configuration carries the product information and trusted public key. Fill in your own license, database and actual economy configuration. Compare downloads against SHA-256 checksums:

```powershell
Get-FileHash -Algorithm SHA256 .\KiteMarket-modern-1.0.0.jar
```
