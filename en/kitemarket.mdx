    <p>Default SQLite suits a single node; MySQL 8 or MariaDB 10.11 supports same-version nodes sharing orders, wallets and claims. Sharing a SQLite file does not create a cross-server market. Each currency uses fixed-precision integer minor units. Vault, PlayerPoints, CoinsEngine and ExcellentEconomy transfers use public interfaces; existing wallet funds remain usable when a gateway is unavailable. Uncertain outcomes enter review without blindly repeating a debit or delivery.</p>
