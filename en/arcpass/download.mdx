## API dependency {#api-dependency}

Reference the API through GitHub Packages with `provided` or `compileOnly`. Do not bundle the SDK in your extension.

<CodeGroup>
```xml Maven
<dependency>
    <groupId>com.kitemc</groupId>
    <artifactId>arcpass-api</artifactId>
    <version>1.9.4</version>
    <scope>provided</scope>
</dependency>
```

```kotlin Gradle (Kotlin DSL)
compileOnly("com.kitemc:arcpass-api:1.9.4")
```

```groovy Gradle (Groovy)
compileOnly 'com.kitemc:arcpass-api:1.9.4'
```
</CodeGroup>
