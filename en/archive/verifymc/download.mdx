## Historical installation {#quick-start}

<Steps>
  <Step title="Get matching files">
    Download the required `VerifyMC-*.jar` from GitHub Releases.
  </Step>
  <Step title="Install the server plugin">
    Place the main JAR in the backend server's `plugins/` directory and restart cleanly.
  </Step>
  <Step title="Optional proxy extension">
    Install the matching `verifymc-proxy-*.jar` on BungeeCord or Velocity if needed.
  </Step>
  <Step title="Read archived configuration">
    Use the archived guide for database, mail and questionnaire configuration. Back up existing configuration and data first.
  </Step>
</Steps>
