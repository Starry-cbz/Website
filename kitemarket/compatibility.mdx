本页区分 `1.0.0` 的目标范围与已有真实验证记录。运行包选择见[下载页](/kitemarket/download)。没有完整报告的组合仍为**未完整验证**；每项记录只适用于列出的构件与场景，不覆盖其他 JAR、游戏版本或经济后端。

| 组件 | 目标范围或限制 | 当前状态 |
|---|---|---|
| Paper / Purpur | 最低目标 Minecraft 1.16.5；使用对应发行包 | Paper 1.21.11 部分交易与界面已有实测；其他组合未完整验证 |
| Folia | 仅实际存在的 Folia 发行版；不声明存在 Folia 1.16.5 | 1.21.11 有仅启动记录；不宣称玩家交易或 IA 认证 |
| legacy / modern / current | Java 字节码目标分别为 11 / 21 / 25；还需满足核心要求 | 构建与实服认证分别检查 |
| 同版本跨服 | Minecraft 版本、市场协议、物品配置和币种定义一致 | Paper 1.21.11 双节点部分流程已验证，完整认证未完成 |
| MySQL 8 | 共享权威账本 | 已有真实集成及界面偏好定向检查；不代表全部故障场景认证 |
| MariaDB 10.11 | 共享权威账本 | 已有独立真实集成及界面偏好定向检查；不代表全部故障场景认证 |
| Vault | Vault API 加实际经济插件；线程、精度和持久性由实现决定 | 按实际经济实现逐一认证 |
| PlayerPoints | 整数币种，余额和变动不能越过后端范围 | 3.3.5 正常充提已验证；完整后端认证未完成 |
| CoinsEngine | 遗留 API 的独立适配器；旧游戏版本与 Folia 不能一概支持 | 未认证 |
| ExcellentEconomy | 改名后的独立 API；不能用其认证代替 CoinsEngine 认证 | 未认证 |
| ItemsAdder v4 兼容 | 使用服主或开发者自有资源／主题，不需要官方 DLC；公开 SDK为Java11，真实IA示例为Java21，运行插件单独准备 | 固定Paper1.21.11／IA4.0.16组合已实际打开白框配置主题与Java市场页；其他资源包和运行组合单独验证 |
| 其他 UI 提供者 | 开发者通过公开 SDK 自行注册；兼容枚举不代表插件内置相应适配器 | 由提供者维护与验证实际运行组合 |

CoinsEngine 与 ExcellentEconomy 在部分发行版的官方要求中明确不支持 Folia。市场支持某个平台不代表所有充提后端也支持它。可让玩家到同版本、已认证的 Paper 网关节点充提；具体行为见[钱包文档](/kitemarket/wallet)。

跨版本代理或协议翻译插件不会改变物品存储契约。客户端可以如何连接由网络自行决定；**共享同一市场的服务器节点必须使用相同 Minecraft 版本**。

当前 IA 证据限于下列代表组合，不认证 Folia、Legacy、1.20.5 或 26.x。未验证或资源未就绪的节点保留完整原版 GUI；主题可用性不会阻止基础交易或资产退出，也不限制第三方自行开发和验证其他主题。见[界面 SDK](/kitemarket/ui-development)及[ItemsAdder 接入与回退](/kitemarket/dlc)。


ProtocolLib 的 `dev-build` 标签会变化，后续同名下载不能自动视为这个构件。以上记录限定这些文件，不表示第三方插件已重新分发，也不构成 Folia 或其他版本认证。KiteMarket JAR、SDK 和示例另有各自摘要；旧页面截图不能自动认证新 JAR。

## 认证记录需要包含什么 {#认证记录需要包含什么}

记录服务器核心与构建号、Java、KiteMarket 构建、数据库版本、经济插件及币种设置，并验证三种交易、并发、充提、领取、重启恢复和授权退出。成功编译或启动不能替代这些验证。

下载页只从实际公开 Release 识别固定文件名，不自动选择第一份 JAR。下载后按 SHA-256 确认准确构件；API、sources 与 Javadoc 不作为服务器插件。

## 分发范围与历史证据 {#分发范围与历史证据}

| 分发 | 版本范围 | 插件字节码 |
|---|---|---|
| Legacy | 1.16.5–1.20.4 | Java 11 |
| Modern | 1.20.5–1.21.11 | Java 21 |
| Current | 首发目标 26.2 | Java 25 |

插件字节码不是核心运行 Java 要求。服务器仍需使用该核心要求的 JVM；不能因为 Legacy 是 Java 11 字节码就用 Java 11 启动所有旧版核心。

下列记录保留准确构件和场景。未验证组合不视为认证，仅启动通过也不代表完整交易、物品保真或经济后端验证。

2026-10-01 的开发测试已在 Paper 1.21.11 build 132、Java 21 的两节点上完成普通一口价购买/领取、部分收购供货/撤单退款、公开竞拍/延时/结算，以及真实客户端的一组高级条件流程。PlayerPoints 3.3.5 的正常充值和提现也有实际余额证据。这些结果只覆盖指定开发环境，不代替完整故障恢复、特殊物品、Purpur、Folia 或其他版本认证。

2026-10-02 另有以下**仅启动验证**：Paper 1.16.5 build 794（Temurin 16）、Folia 1.21.11 build 14（Java 21）和 Paper 26.2 build 129（Java 25）。三者均实际加载对应开发包、连接 MariaDB、执行诊断并正常关闭；没有玩家交易、物品保真或外部经济认证。26.2 服务端有 Windows 性能计数器环境异常，KiteMarket 的启动和诊断仍实际完成。
