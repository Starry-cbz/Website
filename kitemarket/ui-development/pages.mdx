呈现器读取当前页面快照和已登记动作；页面身份、数量范围、报价与交易结果继续由服务端控制。

## 页面、动作与生命周期 {#页面、动作与生命周期}

`UiPage.key()` 是逻辑页面 ID，`UiPage.template()` 是主题选择 ID。原版 `menus` 配置按逻辑 ID，IA `pages` 按模板 ID。

以下清单覆盖通用流程与专题页面。标记“同名”的页面使用自己的页面 ID 作为模板；呈现器始终以当前快照和已登记动作为准。

### 市场与发布 {#市场与发布}

| 页面 ID | 模板 ID | 主要动作 |
|---|---|---|
| `home` | 同名 | 三类交易、发布／编辑草稿、头像、钱包、领取、我的挂单；关闭类型隐藏 |
| `profile` | 同名 | 界面、待核对、历史、社区、自动化及按权限显示的风险／管理入口 |
| `browse` | `browse` / `orders` | 搜索筛选、翻页、详情、保存搜索；个人订单使用 `orders` |
| `browse-filters` | 同名 | 类型、币种、材料、排序、搜索与保存当前条件 |
| `order` | `detail` | 购买、供货、出价、撤单确认、收藏、卖家和真实内容预览 |
| `details` | 同名 | 查看长文本和条件 |
| `editor` | 向导模板，见下文 | 类型、物品或条件、数量、价格、时长 |
| `confirm` | `confirm` / `wizard-confirm` | 最终确认、返回 |
| `preview` | 同名 | 当前规则的背包匹配检查 |
| `supply-preview` | `supply` | 保护格、数量、最大可交、刷新、确认 |

发布编辑器的模板依步骤为 `wizard-type`、`wizard-item`、`wizard-terms`（收购）、`wizard-sale-terms`（出售）、`wizard-auction-terms`（拍卖）；最后确认使用 `wizard-confirm`。

### v1.1 新增页面

以下专题页面的模板 ID 与页面 ID 相同，继续使用同一 `menus`、快照和动作机制。页键、模板与按钮位置不能根据显示文字猜测。

#### 整包、批量与容器 {#v11-bundle-and-bulk-pages}

| 页面 ID | 内容与主要动作 |
|---|---|
| `lot-editor` | 选择真实物品、单品／整包／批量、出售／拍卖、币种、价格、期限及最低量／加价；查看内容和预览 |
| `lot-select` | 从真实背包选择，刷新、查看选择摘要、完成选择 |
| `lot-contents` | 分页只读内容；可对已验证容器继续预览 |
| `lot-batch-plan` | 查看各个独立订单，编辑单项并开始逐份确认 |
| `lot-batch-item` | 真实物品、出售单价／拍卖总价、最低量或加价 |
| `lot-batch-results` | 各单结果、暂停原因与原操作入口；请求下一份人工确认 |
| `container-preview` | 分页显示当前容器实际保存内容，刷新与返回，不允许取出 |
| `order-contents` | 已发布整包的真实条目与数量，分页、刷新及容器预览 |

单品、混合整包和多个独立订单必须分别展示。未发布批量计划只在当前会话保存，不承诺重启后自动继续。

#### 领取来源与本页确认 {#v11-claims-pages}

| 页面 ID | 内容与主要动作 |
|---|---|
| `claims-categories` | 全部来源及实际来源分类 |
| `claims-details` | 当前页所选真实资产、数量和资产／订单／操作引用 |
| `claims-confirm` | 本页条数、数量、背包容量与未知结果提示；取消或确认 |

原 `assets` 页使用源 `46` 分类、`50` 全选／取消本页、`51` 领取所选、`52` 详情；源 `0..35` 勾选本页资产。确认只处理本页最多36项，空间不足项保留，结果未知、会话变化或离线时停止后续项。

#### 业务物品规则 {#v11-business-rule-pages}

| 页面 ID | 内容与主要动作 |
|---|---|
| `rule-business` | 来源／业务 ID、模型、标签、开放字段概览及准入提示 |
| `rule-source` | 读取真实手持身份、选择原版来源、清除身份或仅清业务 ID |
| `rule-model` | 最小／最大模型值、导入、分别清除边界 |
| `rule-tags` | 分页标签、集合输入、手持导入、移除或清空 |
| `rule-fields` | 管理员已开放字段的分页列表与全部清除 |
| `rule-field` | 精确／包含、文本输入、手持标量导入、清除当前字段 |

每次修改先验证独立候选再更新草稿。字段只来自 `items.exposed-fields`；OR 与 EXACT 提示只读，主题不能添加任意脚本或修改真实匹配值。

#### 社区、通知与卖家 {#v11-community-pages}

| 页面 ID | 内容与主要动作 |
|---|---|
| `community` | 收藏、保存搜索、通知、订阅、卖家、排行榜、公开价格及通知开关 |
| `favorites` / `favorite` | 收藏分页，真实订单／不可用提示，打开订单或卖家、移除 |
| `saved-searches` / `subscriptions` | 保存搜索与订阅分页、新增 |
| `saved-search` | 类型、币种、材料、文字、来源、分类、价格区间、标的、展示位、排序、订阅、运行、改名和删除 |
| `saved-search-results` | 实际匹配订单及分页 |
| `seller` | 卖家统计、其订单、币种和UTC日历日窗口 |
| `leaderboard` | 同币种排名、UTC日历日窗口、指标及分页 |
| `notifications` / `notification` | 持久通知、相关订单、明确全部已读；详情更新已读状态 |

聊天通知不会自动标为已读。卖家使用1／7／30个UTC日历日；公开价格使用滚动24小时／7天／30天，不混写这两种窗口。

#### 价格与风险复核 {#v11-risk-pages}

| 页面 ID | 内容与主要动作 |
|---|---|
| `risk` | 本地学习／容量状态、案件、价格、模型及有权限的人工训练 |
| `risk-cases` / `risk-case` | 案件分页、买卖方审计、证据、复核记录、状态／备注及云端确认 |
| `risk-evidence` / `risk-review` | 本案证据／复核历史分页 |
| `risk-prices` / `risk-price` | 同币种可比物品、滚动窗口、完整可比组 |
| `risk-cloud-confirm` | 隐私与额度摘要，发送确认、取消或共享进行中／未确认／已有建议状态 |

公开价格需要浏览权限，其余风险页需要审计权限；状态、训练和云端写入另需管理权限。案件状态不处罚玩家，进行中或未知请求不能通过主题重复发送。

#### 自动化与收益预约 {#v11-automation-pages}

| 页面 ID | 内容与主要动作 |
|---|---|
| `automation` / `automation-confirm` | 未来收益提现、登录提现、自动领取、预约入口及设置确认 |
| `automation-income` | 真实预约分页、刷新与释放本页可释放预约 |
| `automation-income-detail` | 预约状态、提现或仅对 `RESERVED` 的释放，其他状态显示核对提示 |
| `automation-income-confirm` / `automation-release-confirm` | 指定预约／批次摘要、取消和确认 |

关闭未来收益提现不会自动释放已有预约。正在外部执行和未知项不同于普通可用余额，主题必须保留服务端状态与暂停说明。

#### 管理写入工具 {#v11-admin-tools-pages}

| 页面 ID | 内容与主要动作 |
|---|---|
| `admin-tools` / `admin-tools-player` | 目标玩家、原审计、封禁／解禁、撤单、真实资金／资产、手持物品、代上架与导出 |
| `admin-tools-orders` | 指定玩家订单、刷新、分页与处理当前页 |
| `admin-tools-money` / `admin-tools-assets` | 管理员实际可用钱包／可用资产，以及明确移交 |
| `admin-tools-listing` | 真实样品、类型、币种、价格、数量、期限、加价及预览 |
| `admin-tools-export` / `admin-tools-retention` | 有界导出与生成导出的保留策略 |
| `admin-tools-confirm` | 具体目标、实际资产、原因和后果，再由管理员确认 |

工具使用真实已有资金和物品；导出保留只处理本网络生成的过期导出，不删除金融记录或未解决操作。

## 首页与个人中心槽位 {#首页与个人中心槽位}

默认紧凑首页的原始槽位为 `0` 头像、`4` 提示、`8` 领取、`20/22/24` 三类交易、`31` 发布／编辑草稿、`45` 钱包、`53` 我的挂单。

`profile` 使用 `20` 界面偏好、`22` 待核对、`24` 历史、`29` 社区、`31` 管理、`33` 自动化、`35` 风险与 `49` 返回；管理／风险入口随权限显示。待核对列表复用 `history` 页面。

`market.enabled-types` 关闭的类型在首页和发布流程隐藏，源槽位不重排。主题只能呈现已登记的可用动作，不能重新启用模式。

首页布局可通过 `gui.home-layout: auto|compact|legacy` 选择；已有 `menus.home` 在 `auto` 下保留旧首页，迁移规则见[原版 GUI 个性化](/kitemarket/guide#原版-gui-个性化)。

呈现器应读取当前快照和动作，不假设所有首页都使用同一组槽位。

## 数量、金额与结果 {#数量、金额与结果}

数量最大值按实际钱包、可用背包物品、策略及币种限额计算。基础主手单品拍卖取当前物品堆；多槽位发布读取明确选择的完整单品、混合整包或各独立组。充值和提现使用真实余额及可预查的后端容量。

报价变化会要求重新选择，最终提交仍重新校验，主题不得自行放宽上限。

收据提供独立的“查看／复制操作编号”动作，在聊天中显示完整编号和复制入口；摘要保持简短，`inspect` 与只读 API 仍保留编号。

### 交易展示 {#交易展示}

单品一口价按每件单价部分购买，每单最低购买量默认1，可在发布时设为1至发布数量；余量不足最低量时只能买完全部余量。收购按单价分批供货，单品与整包竞拍起价均为整标总价。整包出售也是整个组合总价，不可拆分；批量出售仍是多个独立的单价订单。

主题直接使用服务端金额、输入范围、发布时费用快照与商品说明。数量、总量与已成交量独立展示，保留真实物品属性；整包同时区分标的份数、条目数与实际物品总量。

商品时间和倒计时只反映当前展示，不替代数据库截止校验。领取仍遵守物品自身堆叠上限，空间不足时留在领取箱。

整包 `confirm` 源 `30` 确认、`32` 取消；领取、自动化和管理确认源 `30` 取消、`32` 确认；`risk-cloud-confirm` 源 `30` 发送、`32` 取消。按本页动作令牌处理，不能统一猜测某个槽位永远表示确认。

## 动作与输入 {#动作与输入}

动作清单以当前 `page.actions()` 的槽位→不透明令牌为准。没有令牌的格子只展示信息；不得自己制造动作字符串，或将上一页面的令牌复用到新页。

每次打开或更新都替换页面身份、令牌与回调。

输入通过 `UiCallbacks.input(raw)`，关闭通过 `closed()`；`prompt()` 返回 `false` 时主插件继续使用聊天输入并保留草稿。

## 提供者生命周期 {#提供者生命周期}

| 接口 | 生命周期约定 |
|---|---|
| `register(owner, provider)` | 注册启用中的所属插件，返回可重复关闭的注销句柄 |
| `unavailable(...)` | 只检查本页可用性；`null` 表示就绪，其余为原因码 |
| `open(...)` / `update(...)` | 在玩家上下文呈现克隆快照，替换全部绑定 |
| `refresh(...)` | 可选同身份原地显示刷新；保留绑定，不重开；默认 `false` |
| `isOpen(...)` / `close(...)` | 只识别、关闭自己当前的视图 |
| `prompt(...)` | 原生输入或 `false` 交给主插件聊天输入 |
| `changed(owner)` | 实际资源变化后通知复查，不等于授予交易权 |

服务可能在数据库初始化后才注册。获取为空时监听 `ServiceRegisterEvent`，服务替换时丢弃旧句柄与页面；所属插件停用时注销，主插件会按会话保护回退。

不要在 Folia 全局线程读写玩家库存，示例不声明 Folia 认证。
