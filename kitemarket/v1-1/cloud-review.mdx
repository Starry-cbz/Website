本页属于 [v1.1 候选专题](/kitemarket/v1-1/overview)。云端复核默认关闭；本地分析不依赖远程模型。

## 管理员手动启用

管理员自行选择兼容 chat-completions 的 HTTPS 服务，设置端点、鉴权与模型。启用配置后，每次仍需确认具体案件；不是持续上传全部交易。

```yaml
risk:
  enabled: true
  cloud:
    enabled: false
    endpoint: 'https://your-provider.example/v1/chat/completions'
    api-key: ''
    model: ''
    daily-limit: 20
    maximum-request-bytes: 16384
    maximum-response-bytes: 32768
    timeout-millis: 15000
```

示例保持关闭。确认服务、隐私条款和成本后填写实际配置并启用；示例地址不是 KiteMC 提供的云服务。API key 用于你配置端点的 HTTPS 鉴权，不放入模型证据正文。

默认网络每日20次，请求最多16384字节、响应最多32768字节、超时15秒。不跟随重定向，避免请求被移到另一个端点。

发送前在共享存储同时提交本案请求身份和当日额度，跨节点确认同案也只产生一个发送意图。其他节点显示“进行中”或复用已保存建议，不重新调用服务。

## 发送与不发送

| 数据 | 处理 |
| --- | --- |
| 玩家关联 | 使用按网络、用途分离的 HMAC 假名，不发真实 UUID 或姓名 |
| 证据信号 | 仅本案允许的信号类型、证据引用和数值 |
| 网络或物品关联 | 受控假名及可比摘要，不包含完整原始数据 |
| IP、原物品名称/Lore/NBT | 不发送 |
| 管理员备注、原始事件 | 不发送 |
| 凭据 | 仅端点鉴权所需 HTTP 字段，不作为模型证据 |

假名化不等于第三方绝对无法关联信息。重复关系及数值本身仍可能透露模式，管理员应根据所选服务的保留与处理条款决定是否启用。

本地案件继续保留人工证据和备注，白名单只约束发送给模型的摘要，不删除本地审计数据。

## 响应校验

响应必须采用规定建议字段并引用本案证据。其他案件引用、未知字段/动作、工具调用或无效结构会被拒绝，拒绝结果不会当成已接受建议。

建议只供管理员复核，不执行市场操作、确认外部调用或处罚玩家。云端的“可疑”判断不能替代真实操作证据，也不能绕过 UNKNOWN 处理。

## 关闭与失败

关闭云端、额度耗尽、超时、服务失败或响应被拒绝时，继续本地[案件复核](/kitemarket/v1-1/administration-risk)。普通交易和本地规则不需要远程服务。

超时、请求失败、响应被拒绝或发送节点中断后结果不明确时，保留“结果未确认”记录与已占额度，禁止此案再次发送；重启或切换节点也不会重发。对应案件和证据继续保留，管理员仍可本地复核并向所选服务核对。服务收费及数据处理由所选服务决定。
