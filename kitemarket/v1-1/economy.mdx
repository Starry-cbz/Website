## 费用规则与既有订单 {#v11-fee-rules-and-existing-orders}

原 `market.tax-bps`、`market.taxes` 继续有效，100基点为1%。开启 `fees` 后，按配置顺序选择第一条匹配规则，可区分权限、币种、订单类型和声明式物品条件。没有启用且匹配的新规则时，回退旧税率行为。

```yaml
fees:
  enabled: true
  rules:
    - id: sale-coins
      type: SELL
      currency: coins
      listing-fixed: 100
      listing-bps: 0
      seller-fixed: 0
      seller-bps: 500
      buyer-fixed: 0
      buyer-bps: 200
```

固定金额是币种最小单位。若 `coins.scale: 2`，上例上架费为1.00；成交金额800.00时，买方支付816.00，卖方净收入760.00，上架费另计。不要将最小单位 `100` 显示成100.00。

确认页分别展示上架费、买方费、卖方费。发布成功保存费用快照，重载不改旧订单。部分成交按整单累计金额分摊固定费用和舍入，最后一笔结清余数，不因拆分购买反复收取整单固定费用。

新费用规则将累计固定份额和比例费用合并后取整，再扣除已收费用。整单总费用不变，单次卖方费用不超过本次成交金额，小额尾单可正常结清。

撤回或到期返还未成交托管和冻结，已收上架费不退。旧订单保留原税率和期限，升级不重新收费或延长到期。

<span id="交易限制" />

## 交易限制 {#v11-trading-restrictions}

`policy` 可以限制世界、玩家、物品和创造模式；`policy.limits` 使用第一条匹配权限规则控制挂单数、数量、价格范围、期限、冷却和允许币种。

限制在确认和数据库提交时执行，命令、GUI 与受限开发者请求共享核心校验。修改按钮位置或外观不会改变限制。已有资产仍保留按授权与会话条件允许的退出路径。

<span id="新币种" />

## 经验点、等级与物品币 {#v11-native-currencies}

旧 Vault、PlayerPoints、CoinsEngine、ExcellentEconomy 配置保留原 ID 与网关。新增原生模式：

| `provider` | 配置要求 |
| --- | --- |
| `experience` | 原版经验点，`scale: 0` |
| `experience-level` | 原版等级，`scale: 0`；网络内与经验点二选一 |
| `item` | 真实物品币，`scale: 0`，真实 `item-sample` 和正整数 `denomination` |

经验点与等级不是线性汇率。物品币比较完整样品，材料名称不能代替保存的真实 ItemStack；样品或面额改变会改变币种身份，不能在旧资金仍依赖原定义时直接替换。

充提继续核对指定网关、真实余额、玩家状态、接收容量及背包空间。外部插件不可用时停用相关充提，不显示假零或改用其他适配器。基础配置见[币种配置](/kitemarket/configuration/currencies)。

<span id="缺口补款" />

## 缺口补款 {#v11-shortfall-top-up}

余额不足页读取真实缺口。玩家确认充值成功后，重新读取订单、数量和费用，再打开新的交易确认页。充值成功不等于购买或供货成功，不使用旧报价静默成交。

订单已变化、币种网关不可用或外部结果未知时，按各自结果处理。保留已经充值的市场钱包余额，不反复充值来掩盖后续交易失败。

## 自动提现与领取 {#v11-automatic-withdrawal-and-claims}

未来成交收益提现、登录提现、自动领取分别默认关闭，需要个人确认开启。自动任务按有界批次运行，不承诺一轮处理完所有余额或资产。

未来收益建立独立提现预约，预约、冻结、普通余额和待领资产分别展示。关闭设置不会自动释放已经建立的预约；到预约页查看具体状态，再选择执行或明确释放。

空间不足、网关不可用、会话变更或存在未知外部结果时暂停。自动任务不重复执行 UNKNOWN；先检查原操作和证据，再恢复相关任务。处理步骤见[故障处理](/kitemarket/operations)。
