## 单品和整包

| 标的 | 价格与交付 |
| --- | --- |
| 单品一口价 | 每件单价 × 本次购买量，可以部分成交 |
| 收购 | 每件单价 × 实际供货量，逐件满足完整条件 |
| 竞拍 | 出价为整个标的的总价 |
| 混合整包 | 多项真实资产组成一个不可拆分标的，总价覆盖整包；一次成交交付全部内容 |

整包可包含材料或属性不同的真实物品。确认时逐项查看保存的内容与数量，不把展示箱子或角标当作实际资产。整包没有“只买其中一件”的操作。

已发布订单详情可打开整包内容页，逐项查看真实数量；已验证的容器条目可继续进入只读内部预览。

单品出售仍可设置最低购买量。余量低于最低量时只能买完全部余量，不能通过拆单绕过该规则。相同材料但名称、耐久、附魔、业务身份或完整属性不同的物品，不会因视觉相似自动合并。

## 批量上架

批量上架产生多个独立订单，各自保存价格、期限、物品、费用和结果。它与一份混合整包不同。

预览逐项核对真实库存、发布数量、币种、上架费和成交费用。提交后查看每项结果：成功项已经发布，跳过或暂停项仍需核查。不要因为后续项失败就重新提交成功项。

每份订单仍需人工确认。未发布的选择与批量计划仅保留在当前会话，退出或重启后不会自动继续；已经执行的单笔操作与资金状态则持久保存。

当前发布策略按单品完整选择、批量每个独立组或一个整包标的检查数量。数量、价格或期限超限时显示原因并保留原草稿，不自动调价或降低最低购买量；每份批量确认重新检查当前策略和原请求，不静默改写预览过的条件。

外部副作用未知、会话变化、库存变化或余额不足时，按实际结果暂停。保留操作引用并重新查看；未确认结果不能自动当作失败重放。

## 容器预览与物品保真

容器预览展示实际保存内容，点击查看不能从预览中取出物品。容器本身及内部每一项都必须经过保存、还原和完整属性比较；嵌套或结构超过支持范围会拒绝发布。

预览图标、标题、Lore 或界面主题不能放宽准入。损坏快照、无法完整往返的属性或不支持的内容不会被替换成空容器。

成交、撤回、到期后的真实物品进入领取箱。背包空间不足时继续保留待领，重新查看并腾出空间后领取；不会直接丢在地上。基础说明见[托管与领取](/kitemarket/trading/claims)。

领取箱按来源分类并分页，勾选或全选当前页后查看详情、明确确认，最多36项。空间不足的项跳过保留；结果未确认、会话变化或离线时停止后续项，不重复已确认领取，也不自动继续下一页。文件配置使用[实际整包与领取页面 ID](/kitemarket/configuration/menus#v1-1-bundle-and-claims)。

## 业务身份和高级收购

高级收购在已有材料、文字、附魔和耐久条件上增加业务来源/ID、CustomModelData、PDC 标签和开放标量字段。

| 条件 | 编辑范围 |
| --- | --- |
| 业务来源与 ID | 从手持实物及已启用 ItemsAdder、Oraxen、Nexo、MMOItems 公共 API 读取；不从名称、Lore 或猜测 NBT 得出 |
| CustomModelData | 明确最小/最大范围，或读取手持实物的值 |
| PDC 标签 | 必须同时存在的键名集合，最多32个 |
| 标量字段 | 仅 `items.exposed-fields` 允许的字符串、数字、布尔字段；按原样精确相等或包含 |
| OR | 声明式管理员配置；玩家页面只读，不提供自由脚本 |

每次编辑先校验独立候选副本，再更新原草稿。无效范围、未确认来源或未开放字段不会改坏原条件。

业务身份不等于忽略其他真实属性。未知数据不能由已确认身份安全限定时，继续使用完整 EXACT 样品；完整比较和物品往返准入仍生效。更多基础条件见[精确样品与自定义物品](/kitemarket/trading/items)。

当前 Oraxen 限定验证组合为 Paper 1.21.11、Java 21、Oraxen 1.220.0：一个实际自定义镐完成身份读取、名称搜索、上架、购买与领取，领取后的原生属性和堆叠量与原样品一致。此结果不认证全部 Oraxen 物品或资源包外观；Nexo、MMOItems/MythicLib 的完整运行组合仍未认证。
