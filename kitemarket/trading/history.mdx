## 搜索与筛选 {#搜索与交易收据}

列表可以按交易类型、币种、材料筛选，按即将到期、最新发布或价格排序。业务来源、分类、价格区间、单品／整包和展示位可进一步缩小范围。

搜索支持订单编号、材料 ID、真实名称、Lore 和生效的高级条件文本；`%`、`_` 是普通文字，搜索不检查物品字节或指纹。

筛选在数据库分页前执行，翻页保留条件。

价格排序使用单品一口价与收购的每件单价、整包总价、拍卖当前最高价（无出价时为起拍价）。请先筛选同一标的类型、同一币种；不进行兑换或跨币种估值。

### 文字、材料与价格区间 {#v11-search-fields}

材料筛选支持中文名、英文材料名或命名空间 ID，例如 `钻石`、`DIAMOND`、`minecraft:diamond`，保存时统一为材料 ID。无效输入保留原筛选。

名称搜索使用去掉颜色码的可读文字，逐字渐变不会拆开关键词。现代物品没有自定义显示名时使用公共 API 的 `item_name`；名称匹配不代替业务 ID 或完整属性比较。

保存搜索的价格区间采用非负整数最小货币单位。例如两位小数币种的 `123` 是1.23。切换币种会清空价格上下限，请按新币种重填；其他条件保留。

## 收藏、保存搜索与订阅 {#v11-favorites-saved-searches}

在订单页收藏，从社区页管理，每人最多256个收藏和20个保存搜索。已失效订单仍可移除收藏，不会被显示成可交易库存。

保存搜索保留类型、币种、材料、可读文字、业务来源、分类、价格区间、单品／整包、展示位和排序。每次运行读取当前真实订单；修改文字同步更新材料匹配并保留其他条件，也能匹配没有精确样品的材料收购单。

订阅只提醒后续新匹配订单，不自动购买、供货或出价。条件更新先校验候选，失败不覆盖已保存条件。发现索引最多1024人；容量不足时新增收藏或订阅明确拒绝，不留下半保存状态，未订阅的手动保存搜索仍可使用。

## 持久通知与未读提醒 {#v11-persistent-notifications}

通知覆盖新匹配订单、收藏终态、购买／售出成交和拍卖被超价，最多保存100条。同类型事件按一分钟合并并去重，在市场网络持久保存，离线时不会因聊天未送达而丢失。

登录显示真实未读数，在线每15秒最多合并一条聊天提醒。查看通知详情或明确“全部已读”才更新状态；关闭后续提醒不会删除已有通知或资产记录，读取失败不显示假零值。

管理员可另外启用默认关闭的游戏广播和 Discord。游戏广播按节点60秒汇总；Discord 对真实订单创建消息、更新余量或最高价，并在终态删除，发送失败不回滚成交。无法确认创建结果时保留 `UNKNOWN`，不自动重复创建。配置与隐私范围见[通知与 Discord](/kitemarket/v1-1/community#公开广播和-discord)。

## 卖家窗口、排行与价格参考 {#v11-seller-statistics-and-prices}

卖家资料和排行按卖家、币种累计已提交成交，提供含当天的1、7、30个 **UTC 日历日** 窗口。可按净收入、成交笔数或已售数量切换，再进入卖家统计及订单页；历史数量不是当前库存。

卖家索引最多1024人。超出容量后仍保存个人精确成交统计，但完整排行明确不可用，不将部分卖家包装成全网排行。读取失败与没有数据分别说明，不跨币种混排金额。

价格参考按同币种和完整可比物品分组，使用滚动24小时、7天、30天窗口，展示单位价中位数、数量加权均价和真实成交量。不同属性、不同整包组合或币种不强行合并；无可比数据不显示零估值。参考价不是保证成交的报价，也不是作弊结论。

## 单笔交易收据

点击历史记录打开只读收据，可查看单笔成交数量、币种、总额、按发布快照计算的费用、净收入归属，以及可确认的退款或退物。

卖家收款按关联成交操作计算，不使用订单累计数量推测单笔收入。自己的收款收据不提供买家的原始操作证据。

## 竞拍历史

竞拍者自己的历史包含被超价时释放的冻结金额，以及胜出后的整标结算记录。

自己追加出价不会被记作「被超价」；重复提交或多个节点同时结束不会重复生成这些记录。

## 历史状态与当前状态

历史当时状态与当前操作状态分别显示。旧记录缺少资料时明确标注，不把缺失金额当成 0 或成功。

提交后的结果区分成功、失败与待核对，并提供查看详情及适用的钱包／领取箱入口。

待核对不会提供自动重放、退款或补发。

## 查看操作编号

需要编号时，在收据点击“查看／复制操作编号”，即可在聊天查看完整 UUID 并复制用于 `inspect`。

默认摘要保持简短，审计记录仍保留编号。
