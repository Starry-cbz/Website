买家确定币种、单价、数量、有效期和物品条件，再冻结订单需要的市场资金。

卖家选定符合条件的物品和交货数量，确认后才提交。订单允许部分供货；取消或到期后返还未成交部分的资金。

## 收购模式 {#高级收购}

| 模式 | 匹配方式 |
|---|---|
| 普通材料 | 只接收所选原版材料且没有附带元数据的物品，不会悄悄收进命名、附魔或自定义物品 |
| 高级条件 | 只检查明确设置的规则 |
| 精确样品 | 比较完整物品指纹，忽略数量 |

订单详情和发布确认页会按当前模式说明真正生效的条件。普通材料模式不叠加编辑器里保留的高级条件；高级条件模式显示各项规则；精确样品模式按完整样品属性匹配。

## 高级条件

高级条件采用 **AND**：设置了材料、附魔、耐久和名称时，交货物品必须同时满足它们。材料集合内部任选一种即可。

额外附魔默认禁止，需要在编辑器中明确开启。名称/Lore 只有精确和包含两种匹配，不接受正则表达式。

| 条件 | 含义 |
|---|---|
| 材料 | 从所选材料集合中匹配一种；与其他条件同时生效 |
| 附魔 | 每个指定附魔必须落在自己的等级区间；额外附魔是否允许单独控制 |
| 耐久 | 剩余耐久百分比，0–100；例如 80–100 表示至少保留 80% 耐久；设置后拒绝没有耐久属性的物品 |
| 名称 / Lore | 根据编辑器指定的精确或包含规则匹配；未设置的字段不增加限制 |
| 精确样品 | 匹配数量归一后的真实物品指纹；交易数量独立计算 |

原版高级条件只检查编辑器明确支持的属性。已通过物品准入、但高级条件无法解释的自定义数据需使用[精确样品](/kitemarket/trading/items)；精确模式不解除物品准入限制。

## 条件编辑 {#条件编辑}

### 材料集合

点击「材料集合」从当前服务端的物品列表多选，点击已选项即可移除。

可按材料 ID 筛选、只查看已选材料、加入主手材料，或批量输入 ID；最多 64 种。未通过物品准入的材料不能新增选择。

无效批量输入保留原集合，清空集合后需要重新选材才能发布。

### 附魔

点击「附魔」打开选择器，可按中文名、英文名或 ID 搜索，例如 `锋利`、`Sharpness`、`minecraft:sharpness`；也可清空搜索。取消输入保留原筛选和草稿。

再点击某个附魔，通过最低、最高等级按钮设置区间，也可移除单项条件。

| 等级设置 | 含义 |
|---|---|
| 最低等级为 0 | 允许没有该附魔 |
| 范围 `0–0` | 要求没有该附魔 |

「从主手导入」会用手中物品的附魔替换当前附魔条件，并把各项最低、最高等级设为手中等级。

尚未选择材料时，同时补入主手物品的材料。其他已编辑条件保留，导入后切换为高级条件模式。

### 耐久

「耐久」提供最低、最高百分比按钮，每次调整 5%；点击数值可精调一个整数，也可选择 100%、至少 50% 或导入主手的剩余耐久。

设置范围会要求物品具有耐久属性；清空则不限制耐久。

### 名称与 Lore

名称和 Lore 在独立页面选择「精确」或「包含」，聊天只输入内容，无需 `=`、`~` 条件前缀。Lore 多行用 `\n` 连接。

主手导入使用物品的完整原文本，包括格式和换行，适合保留颜色格式的精确匹配。

清空表示不限制；导入空文本并精确匹配则要求该字段为空。
